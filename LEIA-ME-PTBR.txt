ELDEN RING — CONTADOR DE MORTES (Windows 10/11 x64)

O que faz
- Overlay sempre no topo com MORTES TOTAIS e MORTES NO BOSS.
- Painel de controle separado para corrigir os dois números manualmente.
- No painel, clique em “Definir botão de morte” e aperte a tecla ou botão desejado. Esse comando soma +1 nos dois contadores.
- Clique em “Definir botão de zerar boss” e aperte a tecla ou botão desejado. Esse comando zera somente as mortes do boss.
- É possível usar teclas do teclado ou botões comuns de controles compatíveis com XInput (incluindo muitos controles Xbox e alguns controles genéricos configurados como XInput).
- Segurar os dois atalhos juntos por 0,7 segundo desfaz uma alteração. O histórico guarda até 5 alterações desfeitas, com data e hora completas.
- O histórico do painel exibe data e hora no formato dd/MM/aaaa HH:mm:ss.
- Os números, atalhos e histórico são salvos entre execuções.
- Clique com o botão direito no overlay ou no ícone perto do relógio para abrir o painel.
- Arraste o overlay com o botão esquerdo para mover sua posição.

COMO OBTER O EXE SEM INSTALAR PYTHON OU .NET NO SEU PC
Este ZIP contém o projeto-fonte e uma configuração de compilação no GitHub Actions.
1. Acesse https://github.com/new e crie um repositório chamado EldenRingDeathCounter.
2. Extraia este ZIP no seu computador.
3. Envie os arquivos para o repositório, preservando a pasta oculta .github/workflows/build.yml.
4. No repositório, abra Actions. Escolha “Build Windows EXE” e clique em “Run workflow”, ou abra a execução criada após enviar os arquivos.
5. Quando terminar, abra a execução verde e baixe o item de Artifacts chamado EldenRingDeathCounter-Windows-x64.
6. Extraia esse ZIP e execute EldenRingDeathCounter.exe.

LIMITAÇÕES / OBSERVAÇÕES
- O EXE é compilado para Windows x64 e será autocontido; não exige Python nem instalação do .NET no PC de jogo.
- Para que o overlay fique acima do Elden Ring, configure o jogo em “Janela sem bordas” (borderless). Em tela cheia exclusiva, o Windows pode esconder overlays comuns.
- F7/F8 são atalhos globais. Segurá-las simultaneamente por 0,7 s desfaz uma alteração. A combinação suprime as duas ações simples durante esse uso.
- Esta versão não captura botões de controle diretamente; se quiser usar o controle, será necessário mapear os botões para F7 e F8 em um remapeador compatível. Isso pode variar conforme o controle e o jogo.
- Não há assinatura digital. O Windows SmartScreen pode exibir um aviso para executáveis compilados por você.
